# 과거 구현 보관

이 디렉터리는 삭제 전에 검토할 자료와 과거 구현을 보존합니다. 현재 실행 경로에 포함되지 않습니다.

| 위치 | 내용 |
|---|---|
| `legacy/` | 분리 전 Slack·수집·DB·Flask 소스 참고본 |
| `simulation/` | 과거 일부 기간 초기 적재 및 매일 하루치 추가 적재 시뮬레이션 |
| `simulation/state/` | 기존 적재 체크포인트. 현재 적재기에서 사용하지 않음 |
| `prediction/` | 실제 시연했지만 성능 문제로 제외했던 예측 봇 |
| `collectors/` | CU 과거 범위 수집 및 GS25 페이지 이동 버전 |
| `experiments/` | API·Selenium·상품 파싱 실험 |
| `web_prototype/` | 핵심 서비스 연결이 확인되지 않은 웹 시제품과 정적 리소스 |

Python 참고본은 `.py.txt` 또는 `.py.txt`에 준하는 `.py` 원본 이름 뒤 `.txt`를 붙여
실수로 실행하지 않도록 했습니다. 인증 정보·기존 DB 접속 정보·채널 ID는
`<CONFIG:...>`로 가렸습니다. 실행 가능한 원본이 아니며 설정 문자열이 들어간 부분은 문법상 유효하지 않을 수 있습니다.

예측 모델 `.h5`, 스케일러 `.pkl`, 브랜드별 예측 입력 파일은 저장소에 없습니다.
현재 앱은 TensorFlow 없이 동작하도록 분리했습니다. 향후 모델링 과제는 이 참고본에서 검토할 수 있습니다.

원래의 `.pyc` 캐시 8개는 과거 인증 정보 잔존 가능성을 없애기 위해 삭제했습니다.
대응 소스가 없던 `ai_route` 캐시도 현재 서비스에서 사용하지 않으며 함께 제거했습니다.
공개 브랜치는 과거 커밋과 연결되지 않는 정리본으로 게시합니다.
GitHub 캐시나 기존 복제본은 별도이며, 과거 인증 정보의 폐기·재발급은 소유자 측에서 처리해야 합니다.
