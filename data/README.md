# 로컬 데이터 보관 위치

원본 CSV·Excel 및 데이터 가공 파일은 로컬에만 보관하고 GitHub에는 포함하지 않습니다.
이 디렉터리에서는 이 안내 파일만 버전 관리합니다. DB 백업도 커밋하지 않습니다.

서비스는 환경변수로 설정된 DB의 `all_sale` 등에서 데이터를 조회합니다.
현재 체크아웃에 남겨 둔 파일과 선택적 `cv_store.ingestion` 도구는 과거 자료 검증·복구용이며,
일반적인 서비스 실행의 필수 조건이 아닙니다. 원본이 없으면 파일 적재 명령을 실행할 필요가 없습니다.

데이터 출처와 DB 연동에 필요한 정보는 [데이터 설명](../docs/data_dictionary.md)을 참고하세요.
