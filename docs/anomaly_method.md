# 이상치 알림 판정 기준

2026-11-02 사용자와의 검토에 따라 현재 알림 기준을 다음과 같이 기록합니다.
기존 판정 로직과 임계값은 유지합니다.

## 지표

1. 브랜드별 일일 증감률 = (당일 매출 / 전날 매출 − 1) × 100.
2. 같은 날짜 CU·GS25·세븐일레븐 증감률의 단순 산술평균 계산.
3. 편차(`growth_deviation`) = 해당 브랜드 증감률 − 3사 평균 증감률. 단위는 %p.

DB의 1,209행 중 첫날의 결측 3행을 제외한 1,206행을 검증했습니다.
세 지표 모두 위 계산과 절대오차 0.0001 이내로 일치했습니다.
3사 합산 매출의 증감률을 평균 대신 사용하지 않습니다.

## 채택한 고정 기준

브랜드별 **2024년 전체 기간**의 유효 편차에서 5·95백분위수를 산출하고,
소수 셋째 자리로 반올림한 기존 코드 값을 사용합니다.
재계산에는 정렬된 표본 사이의 선형 보간을 사용했습니다.
첫날 편차는 결측이므로 제외합니다.

| 브랜드 | 5백분위수 재계산 | 기존 하한 | 95백분위수 재계산 | 기존 상한 |
|---|---:|---:|---:|---:|
| CU | -1.343542 | -1.344 | 1.252276 | 1.252 |
| GS25 | -1.460708 | -1.461 | 1.134908 | 1.135 |
| 세븐일레븐 | -1.374168 | -1.374 | 1.394422 | 1.394 |

편차가 상한 **이상**이면 급등, 하한 **이하**이면 급감이며, 결측치는 판정하지 않습니다.
원래 임계값 산출 코드는 발견되지 않았지만, 기존 상·하한 6개가 재계산 및
반올림 결과와 모두 일치합니다. 이는 현재 기준의 근거이며 과거 구현 전부를
복원했다는 의미는 아닙니다. 실행 중 이동평균이나 백분위수를 재계산하지 않습니다.

## 분석 버전과 미확인 사항

- 다운로드한 Tableau 워크북에는 이전 15개 위치(당일 제외)의 10·90백분위수 식이 있습니다.
- 발표 자료의 움직이는 경계선이 최종적으로 어떤 기간·지표·백분위수를 사용했는지는 미확인입니다.
- 14·15·21·28일 및 85·90·95백분위수, 14일 절댓값 평균 후보를 비교했으나
  과거 전체 판정 목록이 없어 단일 알림 사례의 재현만으로 원래 방법을 확정하지 않습니다.
- 고정 기준과의 판정 일치율은 실제 이상치에 대한 탐지 정확도가 아닙니다.
- 2024년 전체로 산출한 기준으로 2024년 과거 날짜를 조회하는 것은 회고적 시연입니다.
  미래 정보를 사용하지 않는 성능 평가나 운영 검증으로 해석하지 않습니다.
  향후 모델링에서는 기준 산출 기간과 평가 기간을 분리해야 합니다.

관련 뉴스·영상은 날짜·브랜드에 따라 연결한 참고 자료이며 인과관계의 증거는 아닙니다.
검증 과정에서 원본 DB와 운영 로직은 변경하지 않았습니다.
개별 매출 데이터·Tableau 데이터 추출본·날짜별 비교 결과는 Git 제외 폴더
`runtime/tableau/`에만 보관하며 공개 저장소에 포함하지 않습니다.
